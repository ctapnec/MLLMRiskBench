## Archive contents and acceptance

Keep the console SQLite data, selected and historical responses, attempts,
judgments, explicit replacement relationships, generation conditions, usage and
cost records, analysis outputs and the referenced prompt media. Preserve source
and licensing attribution. Keep enough source/configuration information to
explain and reproduce the studies on a suitable execution machine.

Do not copy model weights, runtime virtual environments, caches, transport
bundles or provider secrets merely to browse completed results. Framework and
GPU installations are not required for archive viewing, but local inference
still needs suitable hardware and its serving/runtime environment.

Take a consistent database backup and retain the rig copy until the workstation
copy has passed acceptance. Rewrite only installation locators through an
explicit relocation map; preserve scientific identities, output contents and
accounting. Test both campaigns, their selected generation conditions, media,
matched comparisons, charts, costs, downloads and human-review state. Historical
external jobs must remain historical, not falsely appear as running Windows
processes. Opening the archive must not resume paid work or model downloads.

Human ratings, if later collected on Windows, must remain real independent
records with the applicable study arrangements. Automated tests must continue
to use separate storage. Only after these checks should the rig be retired from
the workflow; no rig data is scheduled for deletion by this plan.
